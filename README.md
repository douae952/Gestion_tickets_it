# Gestion Tickets IT

Application web de gestion des tickets informatiques.

## Description

Cette application permet de créer, suivre, rechercher et gérer les tickets IT au sein d'une entreprise.

Elle permet notamment de :

- Créer un nouveau ticket
- Consulter les tickets
- Rechercher un ticket par ID
- Modifier le statut d'un ticket
- Ajouter une solution à un ticket
- Supprimer un ticket
- Consulter les statistiques

## Technologies utilisées

- Python
- Flask
- Pandas
- Excel
- HTML
- CSS
- Matplotlib

## Gestion des utilisateurs

L'application possède trois rôles :

- **Employé** : créer et suivre ses tickets
- **Technicien IT** : consulter et traiter les tickets
- **Administrateur** : gérer l'ensemble des tickets et consulter les statistiques
